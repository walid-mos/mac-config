# Swarm Orchestrator — Spec Manifest

> Generated by /planification on 2026-02-27

## Project Overview

Swarm is a TypeScript CLI tool that orchestrates multiple AI agents to autonomously develop software from a spec. It uses a TDD-driven loop: a planner decomposes work, a test agent writes failing tests (RED), parallel code agents implement the tasks, then parallel reviewers verify quality — looping until tests pass (GREEN). Different LLMs handle different roles (Claude for planning/review, Codex for backend code, Gemini for frontend, GPT-5.3 for testing/security, Kimi K2.5 for documentation) via two backends: Claude Code and OpenCode.

The project lives in `scripts/` in the stow repository, using a stow+npm hybrid pattern. It emits NDJSON events for real-time observability and persists state for resume support, with clean interfaces designed for a future WebSocket layer and web management app.

## Tech Stack

- **Language**: TypeScript (Node.js)
- **Build**: tsup or esbuild (single output to `.local/share/swarm/dist/`)
- **Test runner**: Vitest
- **Package manager**: pnpm
- **CLI framework**: Commander or citty
- **Config format**: TOML (parsed via smol-toml)
- **Deployment**: Stow to `~/.local/` (CLI in PATH via `~/.local/bin/swarm`)
